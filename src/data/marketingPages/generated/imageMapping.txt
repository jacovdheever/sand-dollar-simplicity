Production Notes
Image compression targets
	•	Hero images (1440×600): ≤400KB — use WebP with JPEG fallback
	•	Body images (760–800px wide): ≤150KB — compress in Squoosh or ImageOptim
	•	Portrait mobile screens (400×800): ≤100KB
	•	Client logos: ≤20KB — SVG preferred, PNG fallback

Alt text guidelines
	•	All alt texts are pre-written and SEO-optimised — use exactly as specified
	•	Do not use the filename as alt text
	•	Decorative dividers or background textures: use alt="" (empty)

Video assets
	•	GigExecs Homepage Desktop scroll.mp4 — use as background loop on GigExecs project card or projects page hero (muted, autoplay, loop)
	•	ai-development-agency hero wallpaper video.mp4 — use as hero background on ai-development-agency page (muted, autoplay, loop, fallback to AI Development Dashboard Image.png)
